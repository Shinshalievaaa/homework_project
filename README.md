# Проект "Банковские операции клиента"

## Описание:

Это виджет, который показывает несколько последних успешных банковских операций клиента.
В проекте есть инструменты для эффективной работы с большими объемами данных транзакций,
через генераторы. Финансовые аналитики быстро и удобно могут находить нужную информацию 
о транзакциях и проводить анализ данных. Источником данных о финансовых транзакциях 
может быть JSON-, CSV- или XLSX-файл. 
Для пользователя существует возможность просмотра операций с фильтрами посредством интерфейса.
На странице главной вводиться дата и время в формате YYYY-MM-DD HH:MM:SS, после чего пользователю
возвращается ответ со следующими данными:
1. Приветствие в формате «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» 
в зависимости от текущего времени.
2. По каждой карте: 
   - последние 4 цифры карты; 
   - общая сумма расходов; 
   - кешбэк (1 рубль на каждые 100 рублей).
3. Топ-5 транзакций по сумме платежа.
4. Курс валют.
5. Стоимость акций из S&P500.
Существует сервис "Инвесткопилки", позволяющий копить через округление ваших трат. 
Можно задать комфортный порог округления: 10, 50 или 100 ₽. Траты будут округляться, и разница между 
фактической суммой трат по карте и суммой округления будет попадать на счет "Инвесткопилки".
У пользователя есть возможность использовать отчет "Траты в рабочий/выходной день", 
данные отчета записываются в файл.


## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Shinshalievaaa/homework_project.git
```

## Тестирование

1. В папке htmlcov находится отчет покрытия тестами в формате HTML
2. Для запуска тестирования выполните команду в терминале:
```
pytest
```

## Логирование

1.  Автоматическое логирование информации по выполнению функций, а также их результаты 
выполнения или возникшие ошибки. Логирование может писаться в файл или в консоль


## Использование:

1. Для запуска проекта выполните команду:
```
python main.py
```
